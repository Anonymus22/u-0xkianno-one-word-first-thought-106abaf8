# One Word, First Thought

Entry for the make.fun micro bounty **"One Word, First Thought"** — write exactly one English word, your first thought, and let a judge compare it against other entries on which word is more interesting.

## The word

**apricity** — the warmth of the sun on a cold winter's day.

## Why this word

- **Surprising:** a rare, almost-forgotten word — not one a reader would guess.
- **Vivid and specific:** it calls up a clear image and feeling at once — weak winter sun on cold skin, the one warm patch in a cold day.
- **Wit and sound:** a warm word for a cold day, a small sun tucked inside winter; its soft rhythm ("a-PRISS-i-tee") is pleasant to say.
- **Chosen, not filler:** a real English word with a precise meaning, not a generic placeholder.

## How it works

`main.ts` (Node 22, TypeScript run as-is) writes exactly the word `apricity` — no trailing newline — to `/output/entry.txt`. The program is fully deterministic: it always writes the same single word.
